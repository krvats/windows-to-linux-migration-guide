# Contributing

Thank you for helping others switch safely.

## Good contributions
- Fixing outdated commands, menu names or links (please mention the distro and version).
- Adding a distro, desktop or tool section.
- Adding a field guide (music production, 3D, CAD, science, accounting, and so on) to `docs/08-apps-by-field.md`.
- Translating a document (put it in `docs/<language-code>/`).
- Reporting a step that confused you. If you got lost, the guide is wrong, not you.

## Writing rules
1. **Simple language.** Short sentences. Explain every term once (add it to the glossary).
2. **Every risky step gets a warning box** (use `> **Warning:**`).
3. **Say how to check the result** ("you should see...").
4. **Do not invent facts.** If you are not sure, write "check the official docs" and link them.
5. **Add a "Last reviewed" date** to any file you change.
6. **Never include personal data** (names, serials, keys, private paths).

## How to send a change
1. Fork the repo, create a branch, edit, then open a pull request.
2. Or open an issue using the templates in `.github/ISSUE_TEMPLATE`.

By contributing you agree your work is released under the MIT license.
