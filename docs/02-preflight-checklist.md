# 02. Pre-flight checklist

*Last reviewed: 2026-10-27*

Tick every box before you install anything.

## Hardware and Windows
- [ ] I know my **GPU** (Device Manager, Display adapters): NVIDIA / AMD / Intel and the model
- [ ] I know how to open the **boot menu** (common keys: F12, F11, F10, F8, Esc)
- [ ] **Fast Startup is off** (Control Panel, Power Options, Choose what the power buttons do)
- [ ] **BitLocker is off and fully decrypted** (search Windows for Manage BitLocker)
- [ ] **Secure Boot** plan: many Arch-based distros need it off. Ubuntu, Fedora and Mint can work with it on.
- [ ] My laptop or PC is on power for long copies

## Accounts and licenses
- [ ] Browser sync is on, or passwords are exported
- [ ] 2-step login apps are on my **phone**
- [ ] I know my Steam / Epic / GOG / Discord logins
- [ ] I saved license keys for paid software
- [ ] I wrote down my Wi-Fi password

## Data
- [ ] I know where my **games** are installed
- [ ] I know where my **projects** are
- [ ] I ran a **save backup** (Ludusavi, see [03](03-backup-strategies.md))
- [ ] I copied irreplaceable small files to a **second place** (phone, cloud, USB)
- [ ] I checked the copy opens

## Tools downloaded (do this on good internet)
- [ ] Linux ISO (2 to 6 GB)
- [ ] Rufus (rufus.ie) or balenaEtcher
- [ ] Rescuezilla ISO (only if making a full image)
- [ ] Ludusavi (github.com/mtkennerly/ludusavi)
- [ ] CrystalDiskInfo (check drive health)
- [ ] A USB stick of 8 GB or more (it will be erased)

## Backup drive
- [ ] CrystalDiskInfo says **Good** for the backup drive
- [ ] Enough free space (see [03](03-backup-strategies.md))
- [ ] It is mine, or I have the owner's permission
