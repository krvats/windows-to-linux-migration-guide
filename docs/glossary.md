# Glossary

| Term | Meaning |
|---|---|
| **Distro** | A version of Linux (Ubuntu, CachyOS...) |
| **ISO** | A file that holds an operating system installer |
| **Live USB** | A USB stick that runs Linux without installing |
| **Dual boot** | Two operating systems on one computer, choose at start |
| **Partition** | A section of a drive |
| **Unallocated** | Space on a drive not yet part of any partition |
| **NTFS** | The Windows file system |
| **ext4 / btrfs** | Common Linux file systems |
| **EFI System Partition (ESP)** | Small partition that holds boot files |
| **BIOS / UEFI** | Firmware settings screen at power on |
| **Secure Boot** | A UEFI feature that only boots signed software |
| **BitLocker** | Windows drive encryption |
| **Disk image** | A compressed copy of a whole drive |
| **Wine** | A layer that runs Windows programs on Linux |
| **Proton** | Valve's version of Wine for Steam games |
| **Prefix** | The fake Windows folder a Wine or Proton app uses |
| **Package manager** | The tool that installs software (pacman, apt, dnf) |
| **AUR** | Arch User Repository, community packages for Arch |
| **Rolling release** | Constant updates, no big version upgrades |
| **Tiling window manager** | Windows snap into a grid automatically |
| **Hyprland** | A popular Wayland tiling window manager |
| **Caelestia** | A shell (bar, launcher, widgets) built for Hyprland |
| **Dotfiles** | Your personal config files |
| **Snapshot** | A saved state of the system you can roll back to |
| **Robocopy** | Windows command-line file copy tool |
| **Ludusavi** | A tool that backs up and restores game saves |
