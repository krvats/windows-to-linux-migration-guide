# 14. FAQ

*Last reviewed: 2026-10-27*

**Do I lose my files when I switch?** Not if you follow [03](03-backup-strategies.md). Back up, verify, then install.

**Can I keep Windows and Linux on one drive?** Yes, that is dual boot. See [01](01-choose-your-path.md).

**Can Linux run .exe files?** Not natively. Wine and Proton run many of them. See [07](07-restore-games-and-saves.md).

**Will my Steam games work?** Many do, through Proton. Check ProtonDB.

**Do I need to re-download games?** No. Copy `steamapps` to Linux and add it as a library.

**Are my game saves in AppData lost?** Not if you back them up with Ludusavi or a full profile copy.

**Can I run Adobe apps?** No native versions. Use alternatives or dual boot.

**Which distro should I pick?** See [04](04-choose-a-distro.md). Beginners: Mint or Ubuntu. Gamers who customize: CachyOS or EndeavourOS.

**Is Linux safe without antivirus?** Linux has far fewer desktop threats, but you still need updates, good passwords and care with random scripts.

**Can I go back to Windows?** Yes, with a Windows ISO, or by restoring a disk image if you made one.

**Is it legal and free?** Yes. Most distros are free and open source.

**How long does it take?** About a day of work, plus copying time.

**Will this repo cover my situation?** Probably. If not, open an issue and we will add it.
