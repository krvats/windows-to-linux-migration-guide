# 04. Choose a Linux distribution

*Last reviewed: 2026-10-27. Sizes are approximate and change with every release. Check each website.*

A **distro** is a flavor of Linux. All run the same programs. They differ in updates, defaults and how much you tinker.

## Quick pick

| If you want... | Pick |
|---|---|
| Easiest, Windows-like, stable | **Linux Mint** |
| Most guides and software, beginner friendly | **Ubuntu** |
| Gaming plus heavy customization (Hyprland, Caelestia) | **CachyOS** or **EndeavourOS** |
| Gaming console-style, little tinkering | **Bazzite** |
| Maximum control and you enjoy learning | **Arch Linux** |
| Gaming on Fedora | **Nobara** |
| Rock-solid and old software is fine | **Debian** |
| Great NVIDIA support out of the box, for creators | **Pop!_OS** |

After install, plan for **15 to 30 GB** for the system itself.

## About Caelestia and rice-style themes

Caelestia is a shell for the Hyprland window manager, built around Arch-based systems. It works best on CachyOS, EndeavourOS or Arch. It is harder on Ubuntu or Fedora.

## Switching distros later

Easier the second time. Keep `/home` and games on **separate partitions** and keep your dotfiles in a Git repo. See [12](12-maintenance.md).
