# 00. Should you switch? App and game check

*Last reviewed: 2026-10-27*

Do this **before** you touch any drive. It takes about 10 minutes and can save you days.

## Step 1: List what you use every week

Write down:
- Your **games** (and which launcher: Steam, Epic, GOG, other)
- Your **work apps** (editing, design, coding, office, study tools)
- Any **hardware with special software** (drawing tablet, RGB, capture card, audio interface, printer)

## Step 2: Check each one

| Tool | Use it for |
|---|---|
| [ProtonDB](https://www.protondb.com) | Does this game run on Linux? Look for Platinum, Gold or Silver |
| [AreWeAntiCheatYet](https://areweanticheatyet.com) | Does the game's anti-cheat work on Linux? |
| [AlternativeTo](https://alternativeto.net) | Linux alternatives to Windows apps |
| [WineHQ AppDB](https://appdb.winehq.org) | Will this Windows app run under Wine? |
| [Lutris](https://lutris.net/games) | Install scripts for non-Steam games |

## Step 3: Decide

| Result | Meaning |
|---|---|
| Everything you need works or has an alternative you accept | Go ahead. Single OS is realistic. |
| One or two things do not work | **Dual boot** (see [01](01-choose-your-path.md)) or keep Windows in a virtual machine |
| Your main income tool does not work (for example Adobe Premiere) | Do not go Linux-only. Dual boot or stay |
| Your favorite online game blocks Linux | Dual boot, or accept losing that game |

## Common deal-breakers

- **Adobe** Premiere, After Effects, Photoshop, Illustrator: no native Linux version.
- **Full Visual Studio:** not available. Use VS Code, JetBrains IDEs or Rider.
- **Games with kernel-level anti-cheat** that does not support Linux.
- **Some hardware tools** (certain RGB, capture cards, tablets): check the maker and the community.

## Not deal-breakers (they work)

Steam and thousands of Windows games through Proton, Blender, DaVinci Resolve (with limits, see [08](08-apps-by-field.md)), Godot, Unity, Unreal Editor, OBS, Kdenlive, Krita, GIMP, Firefox, Chrome, Discord, VS Code, Docker, Python, Node.js and most AI tools.

> **Warning:** If you only decide after wiping Windows, going back costs a full day. Decide first.
